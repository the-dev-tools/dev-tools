DevTools Studio is now Stresseur Studio. It's the same app with the same flows, and it's still free, open source and local. This version updates in place, and the first time you open it, your workspaces, flows, environments and credentials move to the Stresseur Studio data folder automatically. If you ever go back to a 1.1.x version, it won't see your data, because it now lives in the Stresseur Studio folder; the old folder is kept when the move had to copy.
